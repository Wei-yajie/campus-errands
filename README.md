# 校园跑腿互助平台

面向大学生的校园互助产品：发布任务、接单跑腿、积累信用。

当前阶段：可运行的静态交互雏形。使用原生 HTML/CSS/JavaScript 模块，无构建依赖。

计划固定公开入口：https://wei-yajie.github.io/campus-errands/ （部署结果以实际访问验收为准）。

## 本地运行

安装 Node.js 后，在此目录执行 `npm start`，打开终端显示的本地地址。`npm test` 验证认证、订单状态与资金守恒规则。

## 演示方式

- 默认陈同学接单，提交合成交付凭证；切换林同学确认收货并查看流水。
- 周同学的学籍报告已过期，可提交双证示例后切换管理员审核。
- 许同学在演示日期的未来 30 天内毕业；工作台可调整日期，体验毕业后 7 天清算提醒。
- 大额任务需确认风险与责任协议；争议暂停结算，由管理员模拟裁决。

模拟时钟初始为 2026-10-31 14:00（中国时间），确保评审时示例任务仍可复现；它不是真实时钟。账户和订单仅存当前浏览器 localStorage，可在页脚重置。

## 部署

GitHub Pages 使用 main 分支根目录部署。入口 `index.html` 使用相对资源路径与 Hash 路由，无需构建。保持仓库名和账号名不变即可保持项目 URL。仓库里的测试工具无需在 Pages 运行。

## 真实能力边界

无真实登录、学籍联网查验、照片上传、支付、提现或跨用户同步。交付凭证为明确标注的合成占位。角色权限与订单检查用于演示，真实业务必须在服务端再次执行。完整双向评价的双方提交后公开、取消退款、差额退款已支持；部分退款、补款和真实通知留待后续版本。

详见 [开发计划](./DEVELOPMENT_PLAN.md)。

重点功能：学生证与可查验学籍证明双重验证；报告到期暂停接新单；确认收货后结算；代买预算与实付差额；信用记录与订单申诉。

首期为原创面试演示，使用合成数据和模拟资金，不收取真实身份材料或真实付款。计划部署至 GitHub Pages，网站发布并验证前不作为已上线作品提交。
